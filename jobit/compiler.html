Nộp Toàn Bộ 3 Câu Cho Giáo Viên Chấm

Hệ thống sẽ lưu trọn vẹn Mã nguồn thực tế bạn viết và Kết quả chấm chi tiết của cả 3 câu vào Google Sheets.

💡 ĐÁP ÁN MẪU & LỜI GIẢI THAM KHẢO (Đã mở sau khi bạn hoàn thành nộp bài):
Đáp án mẫu Bài 1 (Scanner & If-Else): 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int score = scanner.nextInt();
        if (score >= 5) {
            System.out.println("DAT");
        } else {
            System.out.println("KHONG DAT");
        }
    }
}
Đáp án mẫu Bài 2 (Scanner & For Loop): 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        System.out.println(sum);
    }
}
Đáp án mẫu Bài 3 (Scanner & While Loop): 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int energy = 0;
        while (energy < 100) {
            int buff = scanner.nextInt();
            energy += buff;
        }
        System.out.println("HOAN THANH: " + energy);
    }
}
