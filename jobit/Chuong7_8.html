Bắt đầu & mục tiêu

Tình huống

Tưởng tượng bạn có một chiếc hộp đựng tên, điểm hoặc mã sinh viên. Có thể tạo một chiếc hộp dùng cho nhiều kiểu dữ liệu không?

Khái niệm:

Mục tiêu: hiểu Generic Class/Method, wildcard, ràng buộc kiểu; sử dụng String, StringBuffer, Math, mảng, List, Set và Map.

Ví dụ Java

Câu hỏi: Nếu cần lưu tên và điểm trong cùng một “khuôn” mà không viết hai lớp gần giống nhau, điều gì cần linh hoạt?
Gợi ý: Ta cần cho phép kiểu dữ liệu được chọn khi sử dụng lớp hoặc phương thức.
Main.javaJava
// Ý tưởng: cùng một lớp, nhiều kiểu dữ liệu
Hop<String> ten = new Hop<>();
ten.set("Lan");
System.out.println(ten.get());

Generic giúp tái sử dụng code mà vẫn kiểm soát kiểu.

JAVA LAB · BÀI HỌC

Ôn tập bài trước: thừa kế, đa hình, ngoại lệ

Tình huống

Ở chương trước, XeMay và OTo cùng kế thừa PhuongTien nhưng có thể chạy theo cách riêng. Khi dữ liệu không hợp lệ, chương trình có thể xử lý ngoại lệ.

Khái niệm:

extends tạo quan hệ kế thừa; @Override ghi đè phương thức; abstract mô tả lớp/phương thức chưa hoàn thiện; interface quy định hành vi; try/catch xử lý ngoại lệ.

Ví dụ Java

Câu hỏi: Trong ví dụ, vì sao XeMay phải viết lại phương thức chay()?
Gợi ý: Vì PhuongTien khai báo chay() trừu tượng; mỗi lớp con phải cung cấp cách chạy cụ thể.
Main.javaJava
abstract class PhuongTien {
    abstract void chay();
}
class XeMay extends PhuongTien {
    @Override
void chay() {
        System.out.println("Xe may dang chay");
    }
}

Ôn lại extends, override, abstract, interface và try/catch trước khi học tiếp.

Bài tập về nhà trước: Quản lý phương tiện

Đề bài đầy đủ được giữ lại bên dưới. Nhấn vào mũi tên để mở đề hoặc xem lời giải.

Xem đề bài: Quản lý phương tiện

BÀI TẬP VỀ NHÀ: QUẢN LÝ PHƯƠNG TIỆN

Viết chương trình Java quản lý các loại phương tiện giao thông.

Yêu cầu

1. Tạo lớp `PhuongTien` gồm thuộc tính `ten` và phương thức `hienThiTen()`.

2. Tạo hai lớp `XeMay` và `OTo` kế thừa từ `PhuongTien`.

3. Tạo phương thức `chay()` trong `PhuongTien`, ghi đè trong `XeMay` và `OTo` để hiển thị thông báo khác nhau.

4. Chuyển `PhuongTien` thành lớp trừu tượng (`abstract class`) và khai báo `chay()` là phương thức trừu tượng (`abstract method`).

5. Tạo giao diện (`interface`) `CoTheBamCoi` gồm `bamCoi()`. Cho `OTo` cài đặt giao diện này.

6. Tạo `kiemTraTocDo(int tocDo)`. Nếu `tocDo < 0`, ném `IllegalArgumentException` và xử lý bằng `try/catch`.

7. Trong `main()`, tạo ít nhất một `XeMay`, một `OTo` và gọi các phương thức để kiểm tra.

**Yêu cầu nộp bài:** Chương trình biên dịch, chạy được và thể hiện thừa kế → ghi đè → lớp trừu tượng → interface → ngoại lệ và `try/catch`.

Mở lời giải tham khảo (Java)

Đây là một lời giải mẫu. Có thể đặt mỗi lớp trong một file riêng hoặc để chung trong Main.java khi các lớp không khai báo public.

Main.javaJava
interface CoTheBamCoi {
    void bamCoi();
}

abstract class PhuongTien {
    String ten;

    void hienThiTen() {
        System.out.println("Ten: " + ten);
    }

    abstract void chay();

    void kiemTraTocDo(int tocDo) {
        if (tocDo < 0) {
            throw new IllegalArgumentException("Toc do khong duoc am");
        }
        System.out.println("Toc do hop le: " + tocDo);
    }
}

class XeMay extends PhuongTien {
    @Override
void chay() {
        System.out.println("Xe may dang chay");
    }
}

class OTo extends PhuongTien implements CoTheBamCoi {
    @Override
void chay() {
        System.out.println("O to dang chay");
    }

    @Override
public void bamCoi() {
        System.out.println("O to bam coi: bip bip");
    }
}

public class Main {
    public static void main(String[] args) {
        XeMay xeMay = new XeMay();
        xeMay.ten = "Honda";
        xeMay.hienThiTen();
        xeMay.chay();

        OTo oTo = new OTo();
        oTo.ten = "Toyota";
        oTo.hienThiTen();
        oTo.chay();
        oTo.bamCoi();

        try {
            xeMay.kiemTraTocDo(-10);
        } catch (IllegalArgumentException e) {
            System.out.println("Loi: toc do khong hop le");
        }

        oTo.kiemTraTocDo(50);
    }
}

Cách đọc lời giải

PhuongTien là lớp trừu tượng nên không tạo trực tiếp đối tượng PhuongTien. XeMay và OTo kế thừa, mỗi lớp tự định nghĩa chay(). OTo cài đặt CoTheBamCoi. Khi tốc độ âm, throw ném IllegalArgumentException và catch xử lý lỗi.

Câu hỏi: Vì sao không thể viết new PhuongTien()?
Vì PhuongTien là abstract class. Lớp trừu tượng có thể chứa phương thức chưa có phần triển khai và không thể được khởi tạo trực tiếp.

7.1. Lớp tổng quát (Generic Class)

Tình huống

Một chiếc hộp có thể đựng bút, tên hoặc điểm số. Thay vì viết HopChuoi, HopSo, HopDiem riêng, ta tạo một khuôn Hop<T>.

Khái niệm:

Lớp tổng quát là lớp khai báo tham số kiểu như T. Kiểu cụ thể được xác định khi tạo đối tượng, ví dụ Hop<String> hoặc Hop<Integer>.

Ví dụ Java

Câu hỏi: Nếu có hộp đựng tên và hộp đựng điểm, có nhất thiết phải viết hai lớp hộp riêng không?
Gợi ý: Không. Có thể viết Hop<T>, rồi dùng Hop<String> cho tên và Hop<Integer> cho điểm. T là tên tham số kiểu do người lập trình đặt; khi viết Hop<String>, Java hiểu chỗ T là String trong khai báo generic đó.
Main.javaJava
class Hop<T> {
    private T giaTri;
    public void set(T giaTri) {
        this.giaTri = giaTri;
    }
    public T get() {
        return giaTri;
    }
}
public class Main {
    public static void main(String[] args) {
        Hop<String> h1 = new Hop<>();
        h1.set("Lan");
        System.out.println(h1.get());
        Hop<Integer> h2 = new Hop<>();
        h2.set(9);
        System.out.println(h2.get());
    }
}

Không phải ép kiểu thủ công khi lấy dữ liệu; gán sai kiểu sẽ bị báo lỗi khi biên dịch.

7.2. Phương thức tổng quát (Generic Method)

Tình huống

Bạn muốn in tên, số lượng hoặc điểm mà không cần viết nhiều phương thức giống nhau.

Khái niệm:

Phương thức tổng quát tự khai báo tham số kiểu, thường có cú pháp <T> kiểuTraVe tenHam(T thamSo). Lớp chứa nó không nhất thiết phải là lớp tổng quát.

Ví dụ Java

Câu hỏi: Nếu chỉ muốn in tên, số lượng và điểm, có cần viết ba hàm in gần giống nhau không?
Gợi ý: Không. Một phương thức tổng quát có thể nhận các kiểu khác nhau, miễn thao tác bên trong phù hợp với kiểu đó.
Main.javaJava
class TienIch {
    public static <T> void inGiaTri(T x) {
        System.out.println("Gia tri: " + x);
    }
    public static <T> T traVe(T x) {
        return x;
    }
}
public class Main {
    public static void main(String[] args) {
        TienIch.inGiaTri("Xin chao");
        TienIch.inGiaTri(2026);
        double diem = TienIch.traVe(8.5);
        System.out.println(diem);
    }
}

Dùng Generic Method khi một thao tác cần linh hoạt với nhiều kiểu.

7.3. Kiểu con và ký tự đại diện (Wildcard)

Tình huống

Một hàm tính tổng cần đọc danh sách số nguyên hoặc số thực. Java không tự xem List<Integer> là List<Number>.

Khái niệm:

Wildcard ? biểu thị kiểu chưa biết. ? extends Number nhận danh sách Number hoặc lớp con, phù hợp khi đọc số. ? super Integer phù hợp khi cần thêm Integer vào nơi chứa Integer hoặc kiểu cha của nó.

Ví dụ Java

Câu hỏi: Một hàm tính tổng có thể nhận cả danh sách số nguyên và số thập phân không?
Gợi ý: Có. List<? extends Number> cho phép đọc các phần tử thuộc Number hoặc lớp con của Number.
Main.javaJava
import java.util.*;
public class Main {
    static double tong(List<? extends Number> ds) {
        double kq = 0;
        for (Number n : ds) {
            kq += n.doubleValue();
        }
        return kq;
    }
    public static void main(String[] args) {
        List<Integer> a = Arrays.asList(2, 3, 4);
        List<Double> b = Arrays.asList(1.5, 2.5);
        System.out.println(tong(a));
        System.out.println(tong(b));
    }
}

Chỉ cần nắm: extends cho nguồn cung cấp dữ liệu; super cho nơi tiếp nhận dữ liệu.

7.4. Hạn chế và ràng buộc tham số kiểu (Bounds)

Tình huống

Hàm tính toán chỉ dành cho số. Nếu cho phép truyền chuỗi, các phép toán số sẽ không hợp lệ.

Khái niệm:

Ràng buộc kiểu giới hạn những kiểu có thể thay cho T. T extends Number cho phép Number và lớp con như Integer, Double; vì vậy có thể gọi phương thức của Number.

Ví dụ Java

Câu hỏi: Nếu lớp chỉ có thể nhân đôi số, có nên cho phép truyền một tên như "Lan" không?
Gợi ý: Không. T extends Number giới hạn kiểu được dùng vào Number và các lớp con như Integer, Double.
Main.javaJava
class BoSo<T extends Number> {
    private T so;
    public BoSo(T so) { this.so = so; }
    public double gapDoi() {
        return so.doubleValue() * 2;
    }
}
public class Main {
    public static void main(String[] args) {
        BoSo<Integer> a = new BoSo<>(7);
        BoSo<Double> b = new BoSo<>(2.5);
        System.out.println(a.gapDoi());
        System.out.println(b.gapDoi());
        // BoSo<String> c = new BoSo<>("bay"); // Lỗi biên dịch
    }
}

Ràng buộc kiểu giúp phát hiện dữ liệu không phù hợp trước khi chạy.

JAVA LAB · BÀI HỌC

7.5. Quan hệ giữa lớp tổng quát và thừa kế

Tình huống

Một chiếc hộp có thể được mở rộng thành hộp chỉ chứa số nguyên. Lớp con có thể cố định kiểu hoặc tiếp tục giữ tham số kiểu.

Khái niệm:

Lớp generic vẫn có thể được kế thừa. HopSo extends Hop<Integer> cố định T là Integer. Lưu ý: Hop<Integer> không phải kiểu con của Hop<Number>.

Ví dụ Java

Câu hỏi: Một lớp hộp chuyên chứa số nguyên có thể dùng lại mã của lớp Hop<T> không?
Gợi ý: Có. HopSo có thể kế thừa Hop<Integer>, nên dùng lại set() và get() với kiểu Integer.
Main.javaJava
class Hop<T> {
    protected T giaTri;
    public void set(T x) { giaTri = x; }
    public T get() { return giaTri; }
}
class HopSo extends Hop<Integer> {
    public int binhPhuong() {
        return giaTri * giaTri;
    }
}
public class Main {
    public static void main(String[] args) {
        HopSo h = new HopSo();
        h.set(6);
        System.out.println(h.get());
        System.out.println(h.binhPhuong());
    }
}

Kế thừa tái sử dụng hành vi; Generic kiểm soát kiểu dữ liệu.

8.1. String, StringBuffer, Math và mảng (Array)

Tình huống

Ứng dụng lớp học cần ghép họ tên, sửa thông báo, tính căn bậc hai và lưu điểm của cả lớp. Java có sẵn công cụ cho các việc đó.

Khái niệm:

String là chuỗi bất biến; StringBuffer có thể thay đổi nội dung; Math cung cấp hàm toán học; mảng (Array) lưu số lượng phần tử cố định cùng kiểu. Integer, Double là lớp bao (Wrapper Class) cho int, double. Array không phải wrapper class.

Ví dụ Java

Câu hỏi: Nếu cần lưu ba điểm cố định, nên dùng mảng hay List? Nếu cần nối chuỗi nhiều lần thì sao?
Gợi ý: Mảng phù hợp khi số phần tử cố định; StringBuffer phù hợp khi cần sửa/nối nội dung chuỗi nhiều lần.
Main.javaJava
public class Main {
    public static void main(String[] args) {
        String ten = "Lan";
        ten = ten + " Nguyen";
        System.out.println(ten);
        StringBuffer tb = new StringBuffer("Xin");
        tb.append(" chao lop");
        System.out.println(tb);
        System.out.println(Math.max(7, 9));
        System.out.println(Math.sqrt(81));
        int[] diem = {8, 9, 10};
        System.out.println(diem[0]);
        System.out.println(diem.length);
        Integer soDiem = 10;
        Double heSo = 1.5;
        System.out.println(soDiem + heSo);
    }
}

String cho văn bản thông thường; StringBuffer cho chỉnh sửa nhiều lần; mảng phù hợp khi kích thước cố định.

8.2. Container tổng quát: List, Set và Map

Tình huống

Danh sách điểm có thể có giá trị trùng; mã sinh viên cần duy nhất; bảng tra cứu cần nối mã với tên.

Khái niệm:

List giữ thứ tự và cho phép trùng. Set không giữ phần tử trùng. Map lưu cặp khóa–giá trị. Các kiểu như List<String> dùng Generic để xác định kiểu phần tử.

Ví dụ Java

Câu hỏi: Danh sách lớp có thể có tên trùng, nhưng mã sinh viên phải duy nhất. Nên dùng cấu trúc nào?
Gợi ý: Dùng List cho danh sách có thứ tự và có thể trùng; Set cho phần tử không trùng; Map khi cần tra giá trị bằng khóa.
Main.javaJava
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<String> ten = new ArrayList<>();
        ten.add("An"); ten.add("Binh"); ten.add("An");
        System.out.println(ten);
        Set<String> ma = new HashSet<>();
        ma.add("SV01"); ma.add("SV02"); ma.add("SV01");
        System.out.println(ma);
        Map<String, String> danhBa = new HashMap<>();
        danhBa.put("SV01", "An");
        danhBa.put("SV02", "Binh");
        System.out.println(danhBa.get("SV01"));
    }
}

List = danh sách có thứ tự; Set = phần tử duy nhất; Map = tra cứu bằng khóa.

Bài tập tại lớp: Sổ điểm mini

Tình huống

Tạo chương trình lưu điểm, mã sinh viên và tra cứu tên.

Khái niệm:

Yêu cầu: tạo List<Double> chứa 4 điểm; Set<String> chứa mã sinh viên không trùng; Map<String,String> ánh xạ mã sang tên. In kết quả và giải thích vì sao chọn từng cấu trúc.

Ví dụ Java

Câu hỏi: Vì sao mã SV trùng vẫn xuất hiện trong List nhưng không tạo phần tử thứ hai trong Set?
Gợi ý: List cho phép phần tử trùng; Set chỉ lưu các phần tử duy nhất theo quy tắc equals/hashCode của kiểu phần tử.
Main.javaJava
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<Double> diem = new ArrayList<>();
        diem.add(8.0); diem.add(7.5); diem.add(9.0);
        Set<String> ma = new HashSet<>();
        ma.add("SV10"); ma.add("SV11"); ma.add("SV10");
        Map<String, String> ten = new HashMap<>();
        ten.put("SV10", "Mai");
        ten.put("SV11", "Nam");
        System.out.println(diem);
        System.out.println(ma);
        System.out.println(ten.get("SV10"));
    }
}

Chọn cấu trúc theo yêu cầu dữ liệu, không chỉ theo thói quen.

Bài tập về nhà: Quản lý kho sách

Tình huống

Thư viện cần lưu tên sách, mã sách duy nhất và tra cứu tên sách theo mã.

Khái niệm:

Yêu cầu: tạo Hop<T> có set/get; viết Generic Method inGiaTri(T x); tạo List<String> có ít nhất 5 tên sách, trong đó có tên trùng; tạo Set<String> mã sách; tạo Map<String,String> tra mã ra tên; dùng StringBuffer tạo thông báo và Math.max() so sánh hai số.

// Gợi ý khởi đầu
List<String> sach = new ArrayList<>();

sach.add("Co so du lieu");
Set<String> maSach = new HashSet<>();

JAVA LAB · BÀI HỌC

Tổng kết nhanh

Tình huống

Nếu cần một khuôn dùng nhiều kiểu, đọc danh sách số, hay loại mã trùng, hãy chọn đúng công cụ.

Khái niệm:

Generic Class: lớp có tham số kiểu. Generic Method: phương thức có tham số kiểu. Wildcard: ?, ? extends, ? super. Bounds: giới hạn kiểu. String bất biến; StringBuffer thay đổi được; Math là tiện ích toán học; mảng có kích thước cố định; List cho phép trùng; Set không trùng; Map lưu cặp khóa–giá trị.
