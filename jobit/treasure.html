Chinh phục 5 thử thách lập trình (Mỗi câu đúng = 1 điểm, tổng điểm 5/5)

Thử thách 1: Khai báo Biến (+1 Điểm) Còn lại: 3 lần thử

1. Hòm đồ bí mật (Variables)

Khai báo biến chuỗi characterName = "JavaKnight" và số nguyên healthPoint = 100 (Nhớ có dấu chấm phẩy ; ở cuối câu).

Đáp án mẫu:
String characterName = "JavaKnight";
int healthPoint = 100;
Thử thách 2: Câu lệnh điều kiện (+1 Điểm) Còn lại: 3 lần thử

2. Mê cung Điều kiện (if-else)

Viết lệnh if kiểm tra nếu healthPoint > 50 && hasKey == true thì in ra màn hình "Mở cửa thành công!".

Đáp án mẫu:
if (healthPoint > 50 && hasKey == true) {
    System.out.println("Mở cửa thành công!");
}
Thử thách 3: Sửa lỗi Debug (+1 Điểm) Còn lại: 3 lần thử

Thử thách 4: Vòng lặp For (+1 Điểm) Còn lại: 3 lần thử

4. Thu Thập Tiền Xu (Vòng lặp For)

Hiệp sĩ nhặt 5 đồng xu vàng trên đường. Viết vòng lặp for cho biến i chạy từ 1 đến 5, mỗi lần lặp in ra màn hình: "Nhặt đồng xu số " + i.

Đáp án mẫu:
for (int i = 1; i <= 5; i++) {
    System.out.println("Nhặt đồng xu số " + i);
}
Thử thách 5: Vòng lặp While (+1 Điểm) Còn lại: 3 lần thử

5. Hồi Thể Lực (Vòng lặp While)

Uống thuốc hồi máu: Viết vòng lặp while lặp khi energy < 100 thì tăng năng lượng thêm 20 (energy += 20;) và in ra "Đang hồi phục...".

Đáp án mẫu:
while (energy < 100) {
    energy += 20;
    System.out.println("Đang hồi phục...");
}
